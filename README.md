# cv-page

Personal resume/portfolio page inspired by [shuga.blog](https://shuga.blog/).

## Features

- Interactive experience section: hover a job to reveal details in a side panel
- Detail panel slides in aligned to the hovered position
- External company links in each detail view
- Skills, Education, Certifications, Languages, and Others sections
- Minimalist design with Tailwind CSS

## Stack

Plain HTML + Tailwind CSS (CDN). No build step required — just open `index.html`.
